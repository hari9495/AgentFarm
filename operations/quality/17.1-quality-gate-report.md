## Role Architecture Note

The Content Writer role follows the same vertical pattern established by the Developer and Technical Writer roles:

- **Profile layer** (`content-writer-agent-profile.ts`): connector allowlist, local action allowlist, blocked actions `const` array
- **Role-profile layer** (`role-profiles/content-writer-role-profile.ts`): `Set<string>` blocked actions for task-classifier, approval thresholds, blocked keywords
- **Persona layer** (`content-writer-persona-defaults.ts`): default AgentPersonaRecord
- **Memory layer** (`content-writer-episodic-hooks.ts`): pgvector episodic pattern/summary builders
- **MCP layer** (`content-writer-mcp-provisioner.ts`): lazy client provisioning
- **Standup layer** (`content-writer-standup-builder.ts`): `StandupSummary` + daily summary builder
- **Handler layer** (`content-writer/`): brief-parser, draft-builder, fact-checker, editorial-router
- **Runtime wiring** (`runtime-server.ts`): connector policy, action policy, blocked-action guard, MCP pre-warm, episodic/semantic memory writes
- **Classifier wiring** (`task-classifier.ts`): 20 positive keywords + blocked keyword heuristics

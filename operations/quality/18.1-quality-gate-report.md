## Architecture Note

Sprint 18 completes the Content Writer role capability surface. The gap modules form a clean domain layer:

- **Research layer** (`content-research-service.ts`): external data ingestion before drafting
- **Draft layer** (`llm-prose-writer.ts`): LLM prose synthesis from brief spec + brand voice + research
- **Quality layer** (`fact-checker.ts`, `seo-optimizer.ts`): post-draft validation
- **Delivery layer** (`cms-publisher.ts`, `image-sourcer.ts`, `content-scheduler.ts`): multi-channel publication workflow
- **Iteration layer** (`tone-adapter.ts`, `revision-handler.ts`, `brand-voice-learner.ts`): editorial feedback loop

All 10 modules are injectable (caller/fetch/calendarClient params) for unit testing without live external dependencies. The action handler (`content-writer-action-handler.ts`) is the single integration point between the `LocalWorkspaceExecutor` dispatch table and the domain layer.

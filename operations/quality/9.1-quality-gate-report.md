## Sprint 9 Features Shipped

### 1. Fire-Agent Graceful Deprovision (`agent-lifecycle.ts`)
- `POST /v1/agents/:botId/terminate` — creates a `ProvisioningJob` with `status: cleanup_pending` and `triggerSource: termination`, triggering the existing `processCleanupPendingJob()` poller. Guards duplicate jobs; returns `{ reused, jobId, status }` with HTTP 202.
- `GET /v1/agents/:botId/terminate/status` — returns latest termination job; 404 if none.
- Tenant isolation enforced: cross-tenant access rejected unless `session.scope === 'internal'`.

### 2. Semantic Memory / Company Knowledge RAG
- **`POST /v1/knowledge-base/write`** — embeds content via Azure OpenAI, stores in `AgentKnowledgeBase` pgvector table; returns `SemanticMemoryRecord` with HTTP 201.
- **`POST /v1/knowledge-base/search`** — cosine similarity search (`1 - (embedding <=> vector)`) returning top-5 results above 0.70 threshold.
- Pre-task semantic recall wired into `apps/agent-runtime/src/runtime-server.ts`: before each task, searches knowledge base and attaches results as `task.payload._semantic_context` (non-blocking).

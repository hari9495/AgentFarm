## 1. What AgentFarm Is

AgentFarm is a **multi-tenant SaaS platform that rents out autonomous AI "teammates" (agents) to businesses**. A customer signs up on the website, picks one or more agent roles (developer, tester, recruiter, sales rep, support executive, etc.), connects their tools (Jira, GitHub, Slack, email, telephony…), and the agent then executes real work tasks — gated by human approval for risky actions, with a complete audit/evidence trail.

Evidence: root `README.md` product framing; `strategy/vision-and-positioning.md`; `apps/website` signup → onboarding → portal flow; `docs/BRD.md` executive summary; per-role agent implementations in `apps/agent-runtime/src/agents/`.

## 4. Core Product Loop (task lifecycle)

Verified path (CLAUDE.md + route/source structure):

1. **Intake** — task arrives via dashboard/portal UI, SDK/API, webhook, email, or Slack (`trigger-service`), or is self-generated by the orchestrator's schedulers/proactive signals.
2. **Planning** — agent-runtime LLM planner decomposes the task; provider chosen from 9 LLM providers (or `auto` health-score failover).
3. **Risk classification** — LOW executes immediately; MEDIUM/HIGH produce an approval packet → API Gateway approval queue.
4. **Human approval** — operator decides in dashboard; decisions are locked on re-decision (409), latency tracked.
5. **Execution** — 12+ action tiers: file/shell/IDE, browser (Playwright), desktop VM (noVNC + vision loop), connectors (23 registered tools, 34 normalized actions), meetings (STT/TTS).
6. **Evidence & audit** — screenshots, diffs, evidence bundles (HNSW vector search), append-only audit log.
7. **Learning** — approval → knowledge base ingestion; rejection → lesson in long-term memory.
8. **Billing** — usage metering ($0.10/task platform fee per README), subscription enforcement, budget limits (80% warn / 90% throttle).

## 5. Differentiating Capabilities (implemented, not aspirational)

- **Governance-first execution:** kill-switch with 30-second control window, circuit breakers, OPA policy engine, plugin allowlist/killswitch, evidence bundles with TTL/retention (`routes/governance/`, `services/policy-engine`, `services/approval-service`).
- **Compliance disclosure:** EU AI Act Art. 52 / FTC / CA SB 1001 outbound-disclosure chokepoint on every channel (`outbound-disclosure.ts`, disclosure routes/audit).
- **Voice & meetings:** full self-hosted stack — whisper (STT), kokoro/xtts/mms-tts (TTS), voxcpm, FreeSWITCH telephony, Zoom video sidecar + Teams media bot containers (`docker-compose.yml`, `docker/`).
- **Desktop operator:** containerized Xvfb + noVNC desktop with screenshot→LLM→action vision loop (`services/desktop-agent`, `docker/desktop-agent`).
- **Memory system:** 4-layer — short-term (7-day TTL), long-term lessons, episodic per-person (pgvector, GDPR delete), semantic knowledge base (cosine similarity recall pre-task).
- **Multi-agent orchestration:** GOAP A* planner, handoffs, autonomous loops, wake coalescing (`apps/orchestrator`).
- **Sales automation domain:** 13+ Prisma models covering prospects → deals → proposals → negotiations → contracts (ZohoSign) → calls (telephony connectors) → NPS/win-loss. Post-dates all docs.
- **Customer support domain:** SupportIssue/CSAT/chat/diagnosis models + support chat & voice session routes.
